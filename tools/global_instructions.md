## Academic writing skills (scientific papers, reviews, theses, proposals)

For scientific writing tasks, use the matching skill before starting (Claude Code: Skill tool; Codex: `$skill-name`; OpenCode: skill tool):

- `sci-writing-orchestrator`: any manuscript project; routes reviews, articles, letters, rebuttals, proposals and theses, and sets the plan and milestones
- `sci-literature-evidence`: literature search, PDF library, page-cited evidence tables, Crossref DOI checks, citation audits
- `sci-prose-style`: drafting and polishing English and Chinese scientific prose to expert-journal style
- `sci-figure-design`: figure plans, code-drawn data panels, Nano Banana Pro prompts, captions, tables
- `sci-manuscript-build`: single-source bilingual docx builds with numbered citations and native equations
- `sci-manuscript-review`: adversarial audits, referee simulation, readiness scores, response letters

Standing norms for this user's scientific writing:

1. Never invent numbers, citations, DOIs, pages or authors. Every number traces to a source page, with its conditions and accounting scope, and is labelled measured, simulated, projected, estimated, reported-survey or abstract-only.
2. Verify DOIs against Crossref before citing. A claim the cited paper does not contain is removed or re-attributed.
3. Prose: one claim per sentence (median 16–20 words, ceiling about 30), one question per paragraph, topic sentence first. No hype, stock phrases or meta-commentary. Define abbreviations at first use and again in every caption; one term, one spelling.
4. English and Chinese versions carry the same numbers, citations and references block by block.
5. Image models draw schematics only, as drafts that the author redraws unless the target journal allows AI illustrations (then disclose in the caption). Data panels are drawn by code from sourced values and never regenerated by an image model.
6. Edit the source (content file or generator), not generated documents. Archive the current version before restructuring, and never overwrite files that another session is editing.
7. Report what was verified and what remains open.
