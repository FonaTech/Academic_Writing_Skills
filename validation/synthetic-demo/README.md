# Synthetic demonstration: inspected draft

These final EN/ZH DOCX and PDF files were produced from an artificial CSV. They contain no physical water measurements, invented citations or inferential test. Actual AI scientific/visual reviews were performed; human author acceptance remains pending. WithCitations is the builder's variant filename, and the reference count is zero.

The accompanying JSON sections, table metadata, original test CSV, analysis and provenance records are the actual authored inputs. To rebuild in a separate workspace, create a fresh project from the current manuscript kit, copy these authored inputs into it, and run preview. Rebuilding requires new rendered inspection and review records; copied outputs alone do not establish a reviewed state. No prior review attestation is installed into a new project.

This is one small behavioral demonstration. It does not validate real literature, statistics, equations, figures or long manuscripts. The sixteen case-bank scenarios remain hypothetical and unexecuted.
