# Provider-neutral schematic prompting

Use an image model only for a conceptual schematic draft when helpful and permitted. Describe subject, scientific relationships, viewpoint, adjacency, role colors, permitted labels and absent decorations. Use a text-free draft when labels fail; add verified labels in deterministic software. Anatomical, environmental or technical objects are allowed when they are the requested scientific subject.

Never provide data panels or evidential images for model reconstruction/composition. The text-free layout_blocks.png contains blocks only; final plots are composed from their original code-drawn files. The legacy prompt_NBP.md filename carries provider-neutral instructions and does not require a particular model or API.

Request one targeted edit at a time and check the entire affected geometry. A model's promise to preserve numbers is not integrity evidence. Check the actual venue policy, final accuracy and any required disclosure/rights before using an AI-created final. No default publisher permission is assumed.
