# Figure planning

Identify the reader's question and what each panel contributes. Use the fewest display items that make the evidence understandable; fixed counts per manuscript or a universal one-claim-per-figure rule are inappropriate.

Determine venue dimensions, typography and accepted formats. Keep axes, uncertainty, legends and color meanings clear at final size. Multipanel figures may connect several related findings if the caption and text explain their relationship.

Separate source-data/statistics, data plotting, independent schematics and final composition. Data plots are generated by code and composed without an image model. Record source files and evidence keys, analysis, plotting settings, dimensions and licenses. Verify underlying data as well as output integrity. A faithful picture of incorrect data is still incorrect.

The figure kit is a PNG composition helper. If the project requires vector layouts or another plotting environment, use an equivalent transparent provenance/integrity workflow and document the checks rather than converting every figure to raster.
