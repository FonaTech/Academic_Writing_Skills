# Captions and tables

Captions identify what is shown, objects/populations, relevant conditions, measurement or computation method, sample definition, uncertainty/statistics, units, abbreviations and limitations. Give panel-specific explanations and provenance where needed. Keep claims consistent with the underlying evidence and main text. Length and style follow the venue, not a universal sentence or word quota.

Keep acquisition/result method, source role and access state separate. “Abstract-only” is an access limitation; a secondary source is not automatically a measurement. Use the v2 evidence contract. Report ranges, error bars and scope without implying unsupported causality or statistical significance.

Data displays are drawn from source data/evidence with code. Image models may draft separate conceptual schematics subject to the venue policy; they never recreate plotted values or evidential images. Actual final geometry, labels and source meaning require review beyond pixel integrity.

## Tables

- Each table answers a useful question. Include comparison conditions and accounting scope where needed.
- Put numeric units in explicit parenthesized or bracketed column headers, e.g. Mean temperature (°C), and use numeric cells. Mixed-unit cells must state their actual units.
- Define rows, denominators, missing values, sample sizes and uncertainty. Do not represent unavailable values as zero.
- Cell-specific evidence bindings refer to the same row/column/object/metric. The checker inherits an explicit header unit only for a numeric cell, and rejects contradictory units.
- Use appropriate significant digits, readable widths, repeated header rows and the venue's rules. Do not assume all tables must be three-line tables; the provided Word helper is one style.
- Translate paired tables cell by cell when requested; preserve comparison direction, evidence state, numbers, units and citations.

Inspect every final rendered page containing the table or caption. Check that text remains legible and that no row, note or label is clipped.
