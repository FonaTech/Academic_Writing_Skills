# Quantitative reporting

A consequential quantity needs a value/range, unit, object or population, metric definition, relevant conditions, sample/analysis definition, uncertainty and source or raw-data/calculation provenance. Report effect sizes separately from significance claims, and distinguish estimates from observations and forecasts.

| Context | Preserve |
|---|---|
| Clinical/observational | Endpoint, denominator, follow-up, adjustment and effect definition |
| Education/psychology | Scale, grouping/assignment, missingness, paired/cluster structure and analysis |
| Economics | Outcome units, time horizon, population, model assumptions and identification limits |
| Chemistry/metrology | Calibration, blanks, concentration units, detection/quantification criteria and uncertainty |
| Biology/ecology | Experimental unit, technical versus biological replication, controls and processing |
| Computing | Dataset/split, metric, baseline, runs, environment and resource scope |
| Environmental/astronomy | Spatial/temporal coverage, calibration, scenario/reference frame and processing |
| Theory/simulation | Assumptions, parameter regime, numerical convergence and validation scope |

These are review prompts, not a complete methods checklist. Use actual discipline/study standards. Bind quantities locally; the same number in another source is irrelevant. Custom units can be declared in evidence, but automated detection still has coverage limits. Confirm meaning manually.
