# Terminology table

Keep one table per project in the writing plan or in `terminology.md`. Build it from the field's own sources: the target journal's style guide, the field's nomenclature body (for example IUPAC, SI/BIPM, HGNC, ICD, IEEE, ISO standards) and the vocabulary of the two or three most-cited recent reviews. Apply it before the consistency pass; add every new term the first time it appears.

## Rules

- The abbreviation is defined at its first use in the main text, and again in each figure caption and table note.
- An abbreviation used fewer than three times is written out instead.
- Headings avoid undefined abbreviations except universally known ones.
- One term, one spelling: fix hyphenation, capitalisation and the choice among synonyms (for example one of three competing acronyms for the same concept). Competing forms appear only inside cited titles.
- Keep the symbol a source uses for a quantity and define it; do not rename it in the review.
- Chinese text keeps Latin abbreviations, symbols and units, and gives the Chinese term at first use with the abbreviation in parentheses: ⟨中文术语⟩（⟨ABBR⟩）.
- Table cell codes have fixed translations (n.s. ↔ 未注明, n.r. ↔ 未报告) and are defined in both notes.
- Record each decision (chosen form, rejected forms, reason) in the Notes column so later editors do not reintroduce a rejected form.
