# Optional scaffolds

Presets select a document mode and the default precise style. They contain no mandatory word counts, figure counts, domain hierarchy or private research examples. Actual venue rules and study-specific reporting standards determine structure and limits. new_project.py offers generic starting headings, which remain editable.


The [detailed 1.3 editorial scaffolds](editorial-1.3/INDEX.md) preserve its genre/agency outlines and planning ranges. They are optional examples; use the current venue/funder instructions rather than treating an inherited range or template as a present-day rule. All drafts still use the default facts-first chain.
