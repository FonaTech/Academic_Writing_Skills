# Presets

| Preset | Mode | Document |
|---|---|---|
| `review.json` | review | full review article (Nature Reviews / Chem Rev / Adv Mater / Nat Electron style) |
| `review-chapters.json` | review | a block of chapters inside a longer review or book, numbered from CHAPTER |
| `perspective.json` | review | perspective / comment / outlook |
| `article-nature.json` | article | research article, Nature-family |
| `letter.json` | article | letter / communication |
| `conference-paper.json` | article | conference paper (any field; follow the call for papers) |
| `rebuttal.json` | rebuttal | response to reviewers and revised manuscript |
| `proposal-nsfc.json` | proposal | 国家自然科学基金申请书正文 |
| `proposal-rgc.json` | proposal | Hong Kong RGC GRF / ECS proposal |
| `thesis-chapter.json` | thesis | thesis or dissertation chapter |

Presets give defaults for length, display items, structure and checks. The user's journal instructions override them.
