# Case 15: answering hard referee comments

A method study extending Case 03 to the comments that decide a revision: disagreements, requests for new work, conflicting referees and misreadings.

## Principles
- The editor reads the response to decide whether the concerns are resolved. Each answer is written for the editor as much as for the referee.
- Each response follows a short chain: the point restated in one sentence → what was changed, or why not → where the change is (section, page, line, figure).
- The manuscript changes even when the referee is wrong. A misreading shows that the text allowed it.
- Tone is direct and courteous. A thanks formula on every point and defensive phrasing both weaken the answer.

## Kinds of hard comment
| Comment | Method | Constructed response shape |
|---|---|---|
| a request for a new experiment or analysis that is feasible | do it; add the result; cite the new panel | "We measured ⟨quantity⟩ under ⟨condition⟩ (new Fig. 3d). It stays at ⟨v⟩, which rules out ⟨alternative⟩. Change: Section 3.2, lines ⟨a⟩–⟨b⟩." |
| a request that is out of scope or infeasible in the revision time | explain the scope with evidence; offer the strongest substitute; narrow the claim if needed | "A full ⟨study⟩ needs ⟨resources⟩ beyond this work. We now state the claim for ⟨narrower scope⟩ and show ⟨substitute analysis⟩ (Supplementary Fig. S6). Change: abstract and Section 4." |
| a disagreement on interpretation | give the evidence that separates the interpretations; add it to the text | "⟨Alternative⟩ predicts ⟨observable⟩, which we do not see (Fig. 2c). We added this test to Section 3.1." |
| a misreading | quote the passage, clarify it in the text, and say so without blame | "We rewrote the sentence to state that ⟨metric⟩ refers to ⟨scope⟩ (line ⟨a⟩)." |
| conflicting requests from two referees | choose the change that serves the paper's claim; tell both referees and the editor | "Referee 1 asked to shorten ⟨section⟩ and Referee 2 to extend it. We moved ⟨details⟩ to the Supplement and kept the main argument in the text." |
| a request to cite the referee's own or unrelated work | cite it where it supports a claim; otherwise decline briefly with the reason | "The suggested paper concerns ⟨different system⟩; we cite it in Section 1 where ⟨general point⟩ is made." |
| a statistical or methodological objection | answer with the analysis, not with authority | report the test, its assumptions, the effect size and the sensitivity check |

## Drafting order
1. Number and classify every comment, then plan all changes together, because answers interact.
2. Make the changes in the manuscript source and rebuild. Collect the new locations from the rebuilt document.
3. Write the responses from the plan. Each first sentence answers the point.
4. Check that every promised change exists in the rebuilt text, every new number traces to a source, and new text follows the line-of-thought guide.
5. Write the cover letter for the resubmission: three to five main changes, each in one sentence.

## Failure modes
| Failure | Repair |
|---|---|
| "We thank the reviewer for this insightful comment" on every point | thank once at the top; answer each point directly |
| arguing without changing the text | add the clarification the argument contains |
| a promised change missing from the manuscript | verify each promise against the rebuilt document |
| new text added in a different voice | draft it by the same style rules as the rest of the paper |
| a narrowed claim left wide in the abstract or title | apply the narrowing everywhere the claim appears |
