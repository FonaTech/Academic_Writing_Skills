# Case 03 (template): responding to referees

1. Number every comment (R1.1 …). Paste them verbatim into the response skeleton.
2. Classify: correction / new analysis / clarification / disagreement / out of scope. Estimate effort.
3. For corrections and clarifications, change the source text first, rebuild, and note the location.
4. For new analyses, run them, add figures or SI items, and cite them in the response.
5. For disagreements, give evidence (data, citations) and still clarify the text so the point cannot be misread.
6. Draft responses: first sentence answers the point; then evidence; then "Change: Section 4.2, paragraph 3; Fig. 3d".
7. Verify that every promised change exists; re-run the number audit; prepare a tracked-changes copy if requested.
8. Cover letter: three to five bullets of main changes.
