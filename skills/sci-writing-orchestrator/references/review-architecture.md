# Review architecture across disciplines

Choose an organizing axis that answers the review question: mechanisms, themes, competing theories, methods, historical development, populations, applications or a combination. Make the selection basis clear and compare evidence within consistent criteria. No domain hierarchy is imposed.

Give the review's contribution relative to previous work, its coverage limits, synthesis and unanswered questions. Comparator coverage has no fixed number of sentences; provide enough detail for the actual comparison. The default precise profile's sentence-length targets still apply. Do not exclude a scientifically important direction merely because it has fewer papers.

For systematic/scoping reviews select the appropriate protocol/search/appraisal/synthesis branch. Narrative reviews still need honest selection scope, source checks and balanced interpretation. Use the cross-domain case bank to select relevant public reporting/source references.
