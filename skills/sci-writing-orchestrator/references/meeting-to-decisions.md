# Comments and meetings to revisions

Extract each scientific correction, structural request, stylistic preference, requested source and deadline from the supplied comments/transcript. Identify speaker and location where available; uncertain transcription remains uncertain. Build a decision/revision table linked to source blocks.

Distinguish author decisions from suggestions and external claims that require verification. Apply authorized reversible edits, preserve conflicting instructions explicitly and ask only when the conflict materially changes scope or meaning. Do not invent a speaker's approval, experiment, result or commitment.

After revising, check affected evidence, displays, translations and builds. Report the actual changes and remaining questions.
